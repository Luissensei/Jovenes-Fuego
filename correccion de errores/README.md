# Corrección de errores

Esta carpeta está destinada a recopilar los errores, bugs y problemas visuales o funcionales de Jóvenes de Fuego.

## Cómo reportar un error

Puedes subir aquí capturas de pantalla, videos, archivos o documentos con los errores que encuentres.

Si puedes, incluye:
- **Pantalla o módulo:** dónde ocurre.
- **Qué sucede:** descripción del problema.
- **Qué debería suceder:** resultado esperado.
- **Pasos para reproducirlo:** cómo llegar al error.
- **Dispositivo/navegador:** móvil o PC y navegador utilizado.
- **Prioridad:** bloqueante, alta, media o baja.

No incluyas contraseñas, tokens, claves privadas ni datos personales sensibles.

Cuando subas los reportes, podré revisarlos y corregirlos directamente en el repositorio, respetando los roles, permisos y reglas de Firebase.
